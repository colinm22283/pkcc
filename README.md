# PKCC
## Building
The compiler can be built by running make in the root directory. The output
binary will be generated in a folder named build in the project root.

A series of tests are located in the `tests` folder. These can be executed by running `make test-<test_name>` or `make valgrind-<test_name>`. All tests may be invoked by running `make tests`.

This repo successfully builds on Gentoo Linux 6.6.67
